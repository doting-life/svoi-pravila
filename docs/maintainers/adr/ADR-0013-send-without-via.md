# ADR-0013 — Сообщение без «via @бот»: отправляет сам пользователь

Статус: принято · 2026-10-11 · Автор: Claude (CTO), по итогам тестирования 09.10 и исследования 11.10

## Контекст
На тестах пользователи назвали подпись «via @Svoi_PravilaBot» под отправленным сообщением главным ограничителем: собеседник видит, что текст подготовил бот. Исследование 11.10 показало:
- подпись ставит сервер Telegram на любое сообщение, отправленное через inline-режим (поле `via_bot_id`); в Bot API нет способа её убрать;
- флаг `hide_via` в MTProto работает только для встроенных ботов Telegram и выставляется клиентом пользователя;
- подписи нет только там, где «Отправить» нажимает сам человек: копирование и вставка, ссылка Telegram с готовым текстом в поле ввода, своя клавиатура.

Проверка владельцем 11.10:
- `t.me/share/url?text=…` без параметра `url` не работает — открывает telegram.org;
- `t.me/<username>?text=…` открывает чат с этим пользователем с готовым текстом в поле ввода — на телефоне и на компьютере.

## Решение
1. **Правило продукта.** Наш текст попадает в чужой чат только через действие самого пользователя. Бот никогда не отправляет сообщений от имени пользователя.
2. **Пути:**
   - inline-режим — быстрый путь с подписью «via»; об этом сказано при первом запуске;
   - экран «Смягчить» в мини-приложении: «Скопировать и вернуться в чат» — подходит для любого чата;
   - «Отправить {имя}» для партнёра по общим правилам, если у него есть публичное имя пользователя: ссылка `t.me/<username>?text=…` через `openTelegramLink` открывает чат с готовым текстом. Имя пользователя бот получает в момент запроса (`getChat` по Telegram-идентификатору партнёра) и нигде не хранит;
   - своя клавиатура (Android, затем iOS) — полное решение без лишних шагов; отдельное ADR перед началом работ.
3. **Отклонено:**
   - боты Telegram Business / Chat Automation: пишут только туда, где было входящее сообщение за последние 24 часа; к черновику доступа нет — только правка уже отправленного, с пометкой «изменено»; бот получает весь текст подключённых переписок, что противоречит ADR-0002;
   - `t.me/share/url`: требует адрес сайта, а положить вместо него текст — недокументированное использование;
   - юзерботы, модифицированные клиенты, `hide_via`: нарушают правила Telegram и наши принципы.

## Последствия
- Для партнёра по правилам — два нажатия до отправки без подписи; для остальных чатов — копирование и вставка.
- Имя пользователя партнёра не хранится. Если у партнёра нет публичного имени, остаётся копирование.
- Клавиатура становится главным направлением после беты.
