# ADR-0010 — Мини-приложение как единственный интерфейс; закрытая личка бота

Статус: принято · 2026-10-07 · Автор: Claude (CTO), решение владельца 07.10

## Контекст
Владелец решил: всё взаимодействие — через графический интерфейс мини-приложения, а чат с ботом должен быть конфиденциальным и защищённым от внешних манипуляций.

Сейчас личка бота принимает команды и текст: онбординг, контакты, правила, «Расшифровать», `/export`, `/revoke`, `/delete`. Уведомления по общему своду содержат текст правил и имена контактов. Эти данные зашифрованы у нас (C2), но остаются в истории Telegram в открытом виде.

## Решение
1. **Мини-приложение — единственный интерфейс** для всех функций, кроме inline.
2. **Inline остаётся.** Подсказки по `@бот` работают в любом чате. Кнопка над результатами inline открывает мини-приложение (`web_app`), а не личку.
3. **Личка бота закрыта:**
   - бот не обрабатывает команды и содержимое сообщений;
   - на любое входящее сообщение отвечает одним статичным приветствием с кнопкой `web_app`, не чаще раза в 10 минут на пользователя;
   - содержимое сообщений не читается, не логируется и не хранится;
   - списка команд нет, кнопка меню — `web_app`.
4. **Группы и каналы.** Бот в них не работает и при добавлении сразу покидает чат.
5. **Исходящие сообщения бота** — только уведомления по общему своду:
   - без текста правил, имён контактов и любых данных C2;
   - с одной кнопкой `web_app`;
   - решения принимаются в приложении, callback-кнопок нет.
6. **Только в мини-приложении:**
   - онбординг: 18+, раздельные согласия, «что храним», предупреждение «via @бот»;
   - выгрузка данных по одноразовой короткоживущей ссылке через `WebApp.downloadFile`;
   - отзыв согласий и удаление аккаунта;
   - принятие приглашения: параметр `startapp` из подписанного `initData`.
7. **Типы обновлений** (`allowed_updates`): `message`, `inline_query`, `chosen_inline_result`, `my_chat_member`.
8. **Удаляется:**
   - обработчики контактов, правил, расшифровки, прав и онбординга в личке;
   - состояние диалогов в Valkey;
   - callback-токены `sn:` и `pr:` и связанные тексты.

   Исторические события использования с поверхностью `dm` остаются в данных.

## Альтернативы
- Оставить команды как запасной путь — отклонено: лишняя поверхность атаки и два интерфейса с разным поведением.
- Полная тишина бота (без уведомлений) — отклонено владельцем: уведомления по своду нужны, но без содержимого.

## Последствия
- Поверхность атаки меньше: бот не интерпретирует чужой текст в личке.
- Данные C2 больше не попадают в историю Telegram.
- «Расшифровать» пересылкой в личку больше нет: текст вставляется в приложении.
- Внешний вид мини-приложения определяется согласованным макетом (артефакт «Свои Правила — макет мини-приложения», тёплый и спокойный стиль).
