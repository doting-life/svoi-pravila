# ADR-0007 — «Расшифровать» в групповых чатах: не делаем в MVP

Статус: принято · 2026-10-05 · Автор: Claude (CTO) · Основание: спайк 0012 (Cursor), проверка CTO по aiogram 3.31.0 и документации Telegram

## Контекст
«Расшифровать» работает в личке с ботом: пользователь пересылает или копирует входящее сообщение. Спайк 0012 изучил, может ли бот разобрать сообщение прямо в групповом или личном чате пользователя с кем-то, показав результат только ему.

Что есть в Bot API 10.3 (закреплён в aiogram 3.31.0; методы и типы проверены в установленном пакете):
- **Guest Mode** (Bot API 10.0): пользователь упоминает `@bot` в чате или отвечает на его сообщение; бот получает `Update.guest_message` (вызывающее сообщение и, если есть, сообщение, на которое ответили) без членства в чате и без истории; отвечает один раз через `answerGuestQuery`. Ответ публикуется в чат и виден всем участникам.
- **Ephemeral-сообщения** (Bot API 10.2–10.3): `EphemeralMessageParameters(receiver_user_id, callback_query_id, replace_callback_query_message)`, `editEphemeralMessage…`, `deleteEphemeralMessage`, `BotCommand.is_ephemeral`. Видны только адресату и боту; описаны для групп; доставка не гарантирована, особенно если пользователь не в сети. Окно ответа для бота-не-администратора (по отчёту спайка — 15 секунд после действия пользователя) CTO не подтвердил по первоисточнику.
- Членство в группе с выключенным privacy mode или правами администратора, а также Business-подключение дают боту поток чужой переписки — противоречит ADR-0002.

## Решение
1. В MVP и бете «Расшифровать» остаётся только в личке с ботом (пересылка или копирование) и в мини-приложении.
2. Guest Mode, ephemeral-сообщения, членство в группах и Business-подключение не используются.
3. Причины:
   - вызов гостевого бота — обычное сообщение с упоминанием `@bot`, видимое всем участникам: собеседник видит, что пользователь «разбирает» его сообщение; для продукта о бережных разговорах это недопустимо;
   - личные чаты двух людей — основной сценарий продукта; ephemeral-сообщения описаны только для групп, а публичный гостевой ответ в личном чате увидел бы собеседник;
   - приватный показ в группе возможен только цепочкой «публичная заглушка → кнопка → ephemeral» с ограниченным окном и негарантированной доставкой — хрупко и всё равно раскрывает факт обращения;
   - членство с выключенным privacy mode и Business-поток противоречат ADR-0002 (бот не получает переписку, которая ему не нужна).

## Последствия
- Снижение трения в личке (пересылка, копирование, «Вставить в чат») остаётся главным рычагом удобства «Расшифровать».
- Пересмотр — если Telegram даст способ вызвать бота на конкретное сообщение без видимого другим следа (например, действие в контекстном меню сообщения с приватным ответом) и для личных чатов. Проверка — при каждом обновлении aiogram/Bot API в рамках обычного обновления зависимостей.
- Прототип спайка не попадает в `master`; ветка `spike/0012-group-decode` удаляется.
