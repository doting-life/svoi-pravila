# ADR-0003 — Только Telegram, хостинг OVH VPS, официальный релиз вне зоны проекта

Статус: принято · 2026-10-03 · Решение владельца, оформил Claude (CTO)

## Контекст
Первая редакция плана рассматривала адаптер Max, хостинг в РФ и юридическое оформление по 152-ФЗ как часть проекта.

## Решение
1. **Платформа — только Telegram:** бот (inline-режим, личный чат) и мини-приложение. Другие мессенджеры не рассматриваются.
2. **Инфраструктура — OVH VPS.** Всё, включая Postgres, Valkey, мини-приложение и наблюдаемость, разворачивается на нём; бэкапы — в OVH Object Storage.
3. **Граница ответственности.** Проект создаёт функционально полный продукт продакшн-качества. Официальный релиз, юридические тексты, уведомления регуляторов, выбор юрисдикции хранения и дистрибуция — зона выпускающей стороны.

## Последствия
- Задачи «адаптер Max», «связь РФ-хоста с Telegram», «юрист и уведомление РКН» удалены из плана.
- Инженерные требования приватности (ADR-0002) остаются в полном объёме — они определяются чувствительностью данных, а не юрисдикцией.
- Продукт обязан быть переносимым (развёртывание на любом Linux-сервере с Docker по runbook) и технически готовым к юридическому оформлению: версионируемые тексты согласий как данные, экспорт, удаление, реестр данных. Это закрывает задача 0023 (пакет передачи).
- Hexagonal-архитектура сохраняется ради тестируемости и заменяемости LLM-провайдера.
- Доступность GigaChat API с OVH VPS проверяется до 06.10 (D-2).
