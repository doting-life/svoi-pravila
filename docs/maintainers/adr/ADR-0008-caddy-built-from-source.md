# ADR-0008 — Caddy собирается из исходников на актуальном Go

Статус: принято · 2026-10-05 · Автор: Claude (CTO) · Основание: задача 0013-a

## Контекст
Мини-приложение раздаётся Caddy (02-architecture.md §6), на VPS Caddy же будет терминировать TLS (ADR-0005). Официальный образ `caddy:2.11.4` (последний релиз, 3 июня 2026) собран Go 1.26.3 и содержит 17 уязвимостей уровня HIGH в стандартной библиотеке Go и модулях `golang.org/x/{crypto,net,text}`, `google.golang.org/grpc`; у всех есть исправленные версии. Новее образа нет. Гейт CI (Trivy, HIGH/CRITICAL) справедливо падает. Игнорировать находки — подавление, запрещено.

Рассмотренные варианты:
- ждать обновления официального образа — срок неизвестен, а гейт красный уже сейчас;
- заменить Caddy на nginx для мини-приложения — два разных веб-сервера в проекте (Caddy всё равно нужен на VPS ради автоматического TLS) и та же проблема на VPS;
- раздавать статику из FastAPI — лишняя нагрузка и поверхность у сервиса с ПДн, а на VPS Caddy всё равно нужен.

## Решение
1. Бинарник Caddy собирается в многоэтапной сборке из исходников релизного тега официальным инструментом `xcaddy` (версия закреплена) на последнем патче Go из официального образа `golang` (закреплён по дайджесту), `CGO_ENABLED=0`, `-trimpath`.
2. Уязвимые зависимости поднимаются до исправленных версий в сборочном модуле; список поднятых модулей и причина — в Dockerfile рядом с командой сборки. Состав модулей — стандартный Caddy, без сторонних плагинов.
3. Финальный образ минимален: статически собранный бинарник, непривилегированный пользователь, без пакетного менеджера и без файловых capabilities.
4. Тот же способ сборки применяется к Caddy на VPS.
5. Обновление: еженедельный Trivy-скан в CI (уже есть) показывает новые находки; при новом релизе Caddy или патче Go — поднимаются версии в Dockerfile отдельной задачей. Когда официальный образ станет чистым, можно вернуться к нему отдельным решением.

## Последствия
- Сборка образа дольше на время компиляции Go.
- Проект сам отвечает за актуальность версии Go и поднятых модулей Caddy.
