# Модель стоимости LLM на активного пользователя

Владелец документа: Claude (CTO). Редакция: 1.0 · 2026-10-14 — предварительная оценка по размерам промптов. Калибровка по данным прода и замеру 0045 — ред. 1.1.

## 1. Основной цикл продукта (Core Product Loop)

1. Человеку нужно написать трудное сообщение. В любом чате он набирает `@бот черновик`.
2. После паузы набора бот показывает три варианта: «Мягче», «Твёрже», «Проверить». Это **один вызов LLM** (`rewrite`), в промпт подмешиваются договорённости пары.
3. Человек выбирает вариант и отправляет его. Это **обращение** (D-9, `result_chosen`).
4. На трудное входящее сообщение — «Расшифровать» в мини-приложении: подтекст и варианты ответа. Это **два вызова** (`decode`: поток анализа и варианты по схеме).
5. Из разбора — «Сделать правилом» (`suggest_rule`, один вызов). Правило принимают оба, и оно влияет на следующие варианты (шаг 2).

Стоимость определяют шаги 2 и 4. Шаг 5 — редкий и дешёвый.

## 2. Формула

`Стоимость на DAU в день = Σ по операциям (вызовов на DAU × токенов на вызов × цена за токен)`

- **Вызовов `rewrite`** = отправленных через бота сообщений × `g`. Здесь `g` — генераций на одно выбранное сообщение: при наборе Telegram шлёт запрос на каждую паузу. Устаревшие запросы отменяются до провайдера, повтор того же текста берётся из готового результата (§4–5 архитектуры).
- **Токенов на вызов** — вход (промпт, правила, текст) + выход (JSON вариантов) + доля повторов при невалидном ответе (не больше одного повтора).
- **Цена** — billable-токены (вход и выход по одной цене).

## 5. Рычаги и риски

- **Расшифровка — треть стоимости** при одном вызове: модель Pro дороже Lightning в 7,7 раза. Перевод `decode` на Lightning снижает типичный профиль до ≈ 1,75 ₽ — только по результатам eval качества.
- **Размер промпта `rewrite`.** `rewrite@v3` (0043) — до 1,6× `v2`: переписывание станет ≈ 3 000 токенов, типичный профиль — ≈ 3,2 ₽. Размер промпта — гейт задачи 0043.
- **`g`.** Пауза набора (`SP_INLINE_DEBOUNCE_MS`, 600 мс) и отмена до провайдера — главная экономия inline. Рост `g` линейно увеличивает стоимость.
- **Цена Lightning и цены внешнего шлюза** не подтверждены. Модель пересчитывается подстановкой цен, формула не меняется.
